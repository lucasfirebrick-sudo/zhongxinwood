# Assets

- `dist/assets/material.webp`: AI-generated material illustration commissioned for this concept, not an actual product or factory photograph. The landing page labels it as an illustration.
- `dist/assets/timber-bundle.webp`: supplied ZHONGXINWOOD product photograph. The detail section reuses crops of that photograph; it does not imply additional photo evidence.
- Fonts: Barlow Condensed, DM Sans, Libre Caslon Display, downloaded from Google Fonts and self-hosted. OFL license texts are included in assets/licenses.
- All company statements are limited to user-confirmed facts. Sample dimensions in input placeholders are not stock claims.

# Validation notes

Static entrypoints, local references, form source and JavaScript syntax are checked before publishing. No browser visual QA was requested.

The optional `prepare_timber_enquiry` WebMCP action uses the same preparation function as the visible form. No supported WebMCP validation context was available in this environment; registration/execution through that API remain unverified. The normal form does not depend on this optional API.
