# ZHONGXINWOOD

An English landing page for an Okoume sawn timber manufacturer with its own sawmill in Gabon.

## Website

Published with GitHub Pages from the `main` branch, repository root.

## Editing

- `index.html`: page content, product information, dimension diagram and enquiry form.
- `styles.css`: responsive layout, typography and motion.
- `app.js`: dimension interaction and enquiry preparation.
- `assets/`: product photograph, material illustration, locally hosted fonts and font licenses.
- `DESIGN.md`: visual direction and content boundaries.
- `ASSET-NOTES.md`: image provenance and implementation notes.

No build step or package installation is required. Serve this directory with a local HTTP server for development. Changes to the publishing branch are published by GitHub Pages.

## Enquiries

The form prepares a request for copying or downloading. It does not send email, submit to a CRM, or store visitor details. A receiving address or service must be configured before direct submission can be added.

The hero uses a labelled generated material illustration. The product and detail photographs use the supplied real timber-bundle image. Sample measurements are examples, not a stock list.

Font license notices are retained under `assets/licenses/`.
